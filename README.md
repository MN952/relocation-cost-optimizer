# 🚚 Relocation Cost Optimizer Skill

这是一个专为 AI 助手设计的搬家物流费用优化技能（Skill）。

## 🎯 功能简介
通过分析用户的搬家场景、物品属性、材质、体积和路线，AI 能够：
1. **合规核查**：自动识别并预警易燃易爆、管制刀具等禁运/限运物品。
2. **拆分组合方案**：打破单一平台限制，提供“省心全包”、“极致省钱”、“混合最优”三种方案。
3. **隐性费用排查**：主动提示体积重陷阱、上楼费、包装费等容易踩坑的收费项。

## 📂 项目结构
- `SKILL.md`: AI 执行的核心指令文件（包含 YAML 元数据）。

## 🚀 如何使用
将本文件夹作为工作区加载到支持 Skills 的 AI 助手（如 VS Code + Copilot）中，当你询问“搬家怎么寄最便宜”或提供物品清单时，该技能会自动触发。
