# 🚚 搬迁成本优化专家 (Relocation Cost Optimizer)

这是一个专为 AI 助手设计的技能包（Skill），旨在帮助用户在搬家或物流运输场景中实现成本最小化与合规性最大化。

## 🎯 功能简介
本 Skill 赋予 AI 以下核心能力：

1. **合规性预审**：自动识别物品清单中的违禁品或限制运输物品，避免物流扣货风险。
2. **拆分组合策略**：根据物品体积、重量及价值，智能计算“快递+物流+自提”的最优组合方案。
3. **隐形费用预警**：提前识别并提示可能产生的上楼费、打包费、保价费等隐形支出。

## 📂 项目结构
- **SKILL.md**：核心指令文件。包含 AI 执行任务所需的详细逻辑、Prompt 框架及决策树。
- **.gitignore**：Git 版本控制忽略文件配置。

## 🚀 如何使用

### 对于开发者/AI助手
将本仓库克隆到本地工作区（例如 VS Code + Copilot 环境）。当用户在对话中提及“搬家”、“寄大件”或“物流费用”时，AI 将自动加载 `SKILL.md` 中的逻辑进行响应。

### 对于普通用户
1. 确保你的 AI 编程助手已关联此仓库。
2. 直接提问，例如：“我要从北京搬到上海，有3个编织袋衣服和一台冰箱，怎么寄最省钱？”
